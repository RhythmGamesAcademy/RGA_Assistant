# RGA Assistant

Ticket Tool連携の初期フォールバック実装です。設定したDiscordカテゴリ内の
メッセージから指定文字列を検知し、設定した時間が経過した後、検知した
チャンネルにリマインダーを1回送信します。未送信のリマインダーはSQLiteに
保存され、Bot再起動後も引き継がれます。監視中のチャンネルが削除された場合、
そのチャンネルの未送信リマインダーはキャンセルされます。

## セットアップ

1. Python 3.10以降をインストールします。
2. 仮想環境を作成・有効化し、`pip install -r requirements.txt` を実行します。
3. `.env.example` を `.env` にコピーし、以下を設定します。
   - `DISCORD_TOKEN`: Botのトークン。
   - `RGA_TICKET_CATEGORY_IDS`: 監視するDiscordカテゴリID（カンマ区切り）。
     例：`123456789012345678,234567890123456789`
   - `RGA_EXCLUDED_CHANNEL_IDS`: 監視対象から除外するチャンネルID（任意、カンマ区切り）。
     例：`345678901234567890`
   - `RGA_REMINDER_TRIGGER_TEXT`: 未送信リマインダーをキャンセルする完全一致のメッセージ本文。
   - `RGA_REMINDER_VALUE`: リマインダーまでの時間（既定値：`14`）。
   - `RGA_REMINDER_UNIT`: 時間の単位。`seconds`、`minutes`、`hours`、`days`、
     `weeks` のいずれか（既定値：`days`）。
   - `RGA_DATABASE_PATH`: SQLiteデータベースのパス
     （既定値：`data/rga_assistant.sqlite3`）。
4. 監視対象カテゴリでBotに**チャンネルを見る**・**メッセージを送信**権限を付与します。
5. [Discord Developer Portal](https://discord.com/developers/applications)で対象アプリを開き、
   **Bot** > **Privileged Gateway Intents** > **Message Content Intent**を有効にします。
6. `python main.py` を実行します。

Message Content Intentを有効にせずに起動すると、Discordが接続を拒否します。
有効化後も同じエラーが出る場合は、Botトークンが対象アプリのものか確認してから
Botを再起動してください。

## 動作

設定したカテゴリ内のテキストチャンネルで、Bot以外のユーザーが
チャンネルが作成された時点で、その作成日時を起点にリマインダーを自動登録します。
Bot起動時にも既存の監視対象チャンネルを確認し、予定を復元します。
予定時刻になると、チケットチャンネル自身にリマインダーを送信します。

`RGA_REMINDER_TRIGGER_TEXT` と完全に一致するメッセージが投稿された場合は、
そのチャンネルの未送信リマインダーをキャンセルします。一致判定では大文字・
小文字を区別します。文字列の一部が含まれているだけではキャンセルしません。

`RGA_TICKET_CATEGORY_IDS` には複数のカテゴリIDをカンマ区切りで指定できます。
単一カテゴリ用の旧設定 `RGA_TICKET_CATEGORY_ID` も引き続き利用できます。
`RGA_EXCLUDED_CHANNEL_IDS` に指定したチャンネルは、監視カテゴリ内でも対象外です。

リマインダーまでの時間は `RGA_REMINDER_VALUE` と `RGA_REMINDER_UNIT` で指定します。
既定値は14日です。旧設定 `RGA_REMINDER_DAYS` も、日単位の設定として利用できます。
チャンネル作成時刻を起点に予定を作成し、同じチャンネルをBot再起動時に再確認しても
既存の予定はリセットされません。監視対象外のカテゴリや除外チャンネルは対象外です。
予定の確認は5秒間隔で行うため、予定時刻から最大約5秒後に送信されます。
Bot起動時・チャンネル作成時・監視カテゴリへの移動時に予定を登録し、さらに
60秒ごとに監視対象チャンネルを再照合します。Bot停止中に作成されたチャンネルも、
Bot起動後の照合で登録されます。

チャンネルが削除された場合、そのチャンネルの未送信リマインダーはキャンセルされます。
チャンネルの取得やメッセージ送信に失敗した場合は、エラーをログに記録して再試行します。
Discordへの送信後、データベースの状態を更新する前にプロセスが異常終了すると、
再起動後に同じリマインダーが再送される可能性があります。メッセージ本文はメモリ上で
照合するだけで、データベースには保存しません。
